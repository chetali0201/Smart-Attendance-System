# 📋 Smart Attendance System

A simple and user-friendly web-based attendance management system designed to make employee attendance tracking easier and more organized.

## 🚀 Features

* Employee check-in and check-out
* Attendance record management
* Employee details management
* Photo capture during attendance
* Attendance history
* Dashboard for attendance overview
* Export attendance data to Excel
* Responsive and easy-to-use interface

## 🛠️ Tech Stack

### Frontend

* React.js
* Vite
* Tailwind CSS

### Backend

* Node.js
* Express.js
* MongoDB

### Other Technologies

* Cloudinary for image storage
* REST API

## 📂 Project Structure

```text
Smart-Attendance-System/
│
├── frontend/
│   └── React frontend
│
└── backend/
    └── Node.js + Express backend
```

## ⚙️ Installation

### 1. Clone the repository

```bash
git clone https://github.com/chetali0201/Smart-Attendance-System.git
cd Smart-Attendance-System
```

### 2. Install frontend dependencies

```bash
cd frontend
npm install
npm run dev
```

### 3. Install backend dependencies

```bash
cd ../backend
npm install
npm start
```

## 🔐 Environment Variables

Create a `.env` file in the backend folder and add your required environment variables.

```env
PORT=5000
MONGO_URI=your_mongodb_connection_string
CLOUDINARY_CLOUD_NAME=your_cloudinary_cloud_name
CLOUDINARY_API_KEY=your_cloudinary_api_key
CLOUDINARY_API_SECRET=your_cloudinary_api_secret
```

**Never upload your `.env` file or API keys to GitHub.**

## 🎯 Purpose

The purpose of this project is to replace manual attendance records with a digital system that makes attendance tracking faster, easier, and more reliable.
